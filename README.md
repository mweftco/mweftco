# M&WEFTCO Website Product System

This version keeps the existing M&WEFTCO design and adds:
- Add Product
- Edit Product
- Delete Product
- Product name, price, category, image URL, description
- Publish to Website button
- Browser localStorage persistence

## Important
This is a zero-cost frontend starter. Products are saved in the browser's localStorage, so they are not yet shared between different devices/browsers and do not upload image files to GitHub automatically.

For true online publishing from an admin panel to the GitHub Pages website, the next step is a secure GitHub API/backend workflow. Do not put a GitHub token directly in public HTML/JavaScript.
